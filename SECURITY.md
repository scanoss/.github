# Security Policy

SCANOSS takes the security of its software and services seriously. This policy
applies to every repository in the [SCANOSS GitHub organization](https://github.com/scanoss)
that does not publish its own `SECURITY.md`.

## Reporting a vulnerability

Please **do not** open a public issue, pull request or discussion for a security
vulnerability.

Report it privately through GitHub instead:

1. Open the affected repository.
2. Go to the **Security** tab.
3. Click **Report a vulnerability**.

Your report is visible only to the SCANOSS maintainers. Please include:

- the affected repository, component and version (or commit);
- a description of the issue and its impact;
- steps to reproduce, or a proof of concept;
- any suggested fix or mitigation.

## What to expect

- We acknowledge new reports within **3 business days**.
- We keep you informed while we investigate and fix the issue.
- We coordinate disclosure with you and credit you in the advisory, unless you
  prefer to stay anonymous.

## Supported versions

Security fixes are released for the latest released version of each project.
Upgrade to the latest release to receive them.
